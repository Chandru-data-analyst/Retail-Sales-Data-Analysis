# Retail Sales Data Analysis

## Project Overview
This project analyzes retail sales data using SQL Server and Power BI. The goal of the project is to understand sales performance, identify top products, analyze regional sales distribution, and track sales trends.

## Tools Used
- SQL Server
- Power BI
- DAX

## Data Cleaning
The dataset was cleaned using SQL by performing the following steps:
- Removed unnecessary columns
- Checked for null values
- Removed duplicate records
- Trimmed extra spaces in text fields
- Verified data types

## Data Analysis
SQL queries were used to answer business questions such as:
- Total Sales
- Sales by Category
- Top 10 Products
- Sales by Region
- Monthly Sales Trend

## Dashboard
An interactive Power BI dashboard was created to visualize key performance indicators and business insights.

## Key Insights
- West region generates the highest revenue
- Technology category contributes the highest sales
- Canon imageCLASS printer is the top selling product
- Sales peaks during the last quarter of the year
